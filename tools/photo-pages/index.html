Local tool

Photo PagesRuns on your PC

Turn a photo selection into framed A4 PDF pages. Photos are read from your own computer and the PDF is built locally — nothing is uploaded.

Start it on your computer

Photo Pages needs a small Node.js server because it reads and writes photo files on disk. That is why it is not hosted on GitHub Pages with the rest of Northstar.

  1. Install Node.js 20 or newer.
  2. Open a terminal in tools/photo-pages.
  3. Run npm install the first time only.
  4. Run npm start.
  5. Open http://127.0.0.1:4173 in your browser.
Open Photo Pages ↗

Private by default. The server binds to 127.0.0.1, so only this computer can reach it. Uploaded copies, thumbnails, previews, and the PDF all stay in the local data/ folder. Back up that folder to keep your library.
