# Northstar Goals

The savings and weight tracker inside the Northstar hub.

- Savings goals per person, with dated contributions and weekly, bi-weekly, or monthly recurring rules.
- Weight goals, weigh-ins, kg/lb display, and a trend chart.
- Shared PIN via Supabase. See `../../supabase/schema.sql`.
- Demo mode: `http://localhost:8080/apps/goals/?local=1`.

For setup, local hosting, and publishing, see the [project README](../../README.md).
